Ensenada Run — logo animado

SVG incrustado en este archivo (sin imágenes externas). Los dos colores se definen con las variables --c1a / --c1b y --c2a / --c2b, con degradado, cambio de color animado y barrido de reflejo. El botón Descargar SVG guarda el logo con los colores actuales (la animación se reproduce al abrirlo en un navegador) y Descargar PNG guarda una imagen con transparencia a 3x.
